## 当前结论

RAG 未达到预设 70% 数值准确率目标，也没有超过全材料基线。
其输入 token 约减少 72%，本次报告费用约减少 41%，但准确率下降了 20 个百分点。
该结果只适用于此次小样本、材料范围和配置，不说明 RAG 一般比全材料差。
独立数字判分不证明公式、单位或引用语义正确，逐题人工审核尚未完成。

## 失败类型与证据

- 检索不足：RAG 拒答 7 题，其中 6 题没有覆盖全部标注证据。缺少总计、特定年份或表格行时，模型未能计算。
- 下降方向：MRK/2013/page_125.pdf-4 和 AWK/2017/page_148.pdf-1 两组均将“下降百分比”写为正的下降幅度，而标准执行答案为负变化率。固定判分保留为错误，没有事后取绝对值；需要在讨论中解释表达约定差异。
- 引用数值校验：全材料 TFX/2015/page_89.pdf-3 将负数来源作为正数操作数，被校验器拦截。
- 输出预算：全材料 PNC/2014/page_111.pdf-1、C/2008/page_44.pdf-1，以及 RAG 的同两题，报告 completion_tokens=1600，达到请求上限且没有有效答案。可能是推理消耗预算所致；未记录原始 finish_reason，不能据此断言全部失败的根因。
- 其他无效输出：全材料 CDW/2015/page_93.pdf-1 无有效结构化答案，但没有到达上述上限，原因尚未确定。
- 数值／公式解释差异：JPM/2018/page_90.pdf-3 两组，及全材料 SNA/2012/page_110.pdf-3，与标准执行答案不符，需进一步人工检查原题与标注，不能仅凭差异认定哪方语义正确。

## 费用和测量限制

本次正式实验共 40 次模型调用，API usage.cost 合计 $0.035977397。
另一次完整开发测试 20 次调用合计 $0.016236252；本轮合计 60 次调用，费用 $0.052213649。
此前单题连通性测试不计入本轮费用。
费用采用返回的 usage.cost 原值；个别行该字段为零而 upstream_inference_cost 非零，原始 JSONL 已保留，最终账单请核对 OpenRouter。
本地计算、下载和索引成本不计入 API 费用。正式计时排除了预加载模型与生成向量的准备时间。
每题影响 5 个百分点，样本不确定性较大；metrics.json 提供数值准确率的 Wilson 95% 区间。

## 文件用途

- all_results.csv：60 行（三种方案各 20 行），包含问题、预测、标准答案、状态、证据覆盖、耗时、token、费用和人工审核空栏。
- full.jsonl / rag.jsonl / keyword.jsonl：逐题完整证据、模型解析结果和 API usage。
- metrics.json / summary.json：汇总指标。
- run.json：题号、模型、数据版本与源代码／提示词哈希。
- report.md：英文汇总和失败清单。
