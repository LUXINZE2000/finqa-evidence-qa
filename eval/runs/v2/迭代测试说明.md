这是已经用于诊断的同一批 20 道 FinQA public test 题，不是新的独立留出集。
首轮结果保留在 `20260928T093919386066Z`，本轮未更换题目或改写 `exe_ans`。

|---|---:|---:|---:|---:|

修复版 RAG 的五块核心证据平均召回率为 83.75%，核心块单独找全标注证据 15/20；
加入相邻文本及同一表格行后，平均召回率为 90%，找全 17/20。
平均额外加入 7.2 块上下文。关键词 BM25 的标注证据覆盖仍是 10/20。
RAG 与修复版全材料相比输入 tokens 少约 45%，费用低约 17%，但中位耗时略高，
且数值正确题少一题。相对首轮 RAG，本轮上下文与费用均增加。
两组配置均有改动，数据不能用于单独证明哪一项改动带来多少提升。

## 引用与标签初审

`citation_review.csv` 对 40 条模型结果作初步核查：34 条在日志的引文、年份／单位标签
及运算上相互支持，5 条存在题意或数据口径争议，1 条拒答。它不等同独立财务专家认证。
原始 `exe_ans` 分数始终是上表主指标。

- `SNA/2012/page_110.pdf-3`：表格给出 707 千股及每股 $48.87，乘积为 34,551.09 千，
  与数据集文字答案 34,551 相符；标注程序却做减法并将 `exe_ans` 写为 658.13。
  两组均按主指标计错。若只将此一题按文字答案另行核对，全材料为 18/20，RAG 为 17/20；
  这个附加数字不能替代原始基准分。
- `PNC/2014/page_111.pdf-1`：表格的 2616 与 2572 百万美元相差 0.044 十亿美元，
  文字说明却将两年都写为 2.6 十亿美元，标注答案为 0。两组采用表格精度而计错。
- `JPM/2018/page_90.pdf-3`：两组直接读取所问的 2018 年平均资产 2,229,188 百万美元；
  标注程序又将其除以 2.50% 得到 89,167,520。题意与该计算的关系需要领域复核。
- `TFX/2015/page_89.pdf-3`：RAG 用 2015 项目和 2014 调整计划两行相加得到 7,989，
  数值通过，但“排除往年项目”的范围仍有解释空间。
- `MRO/2006/page_93.pdf-1`：修复版 RAG 唯一拒答。所需表格未进入五块核心证据，
  也没有被邻近上下文扩展带入，属于剩余检索失败。

本轮开发集结果：RAG 9/10；全材料 8/10，其中一题接口请求超过 60 秒，按错误计分且
未自动重试。正式测试没有接口错误。所有费用来自 OpenRouter 返回的 `usage.cost`；
本地模型运行与索引成本未计入。样本仅 20 题，每题改变准确率 5 个百分点。

文件：`all_results.csv` 为逐题汇总；`full.jsonl`、`rag.jsonl` 与 `keyword.jsonl` 保留证据、
运算和 token 用量；`run.json` 保留数据与源码哈希；`citation_review.csv` 记录初审状态。
