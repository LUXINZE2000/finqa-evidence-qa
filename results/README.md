# Local run outputs

`scripts.run_evaluation` writes each new run to a timestamped directory here. These ad hoc directories are ignored by Git. The reviewed, unchanged v1 and v2 test records are checked in under [`../eval/runs/`](../eval/runs/), with their configuration, per-case logs, metrics, and review notes. See [`../eval/README.md`](../eval/README.md) before interpreting the scores.
